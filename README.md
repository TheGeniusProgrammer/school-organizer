# School Organizer 📚

Eine serverbasierte Web-Anwendung zur Lern- und Schulorganisation. Strukturiere deinen Schulalltag, verwalte Hausaufgaben, Prüfungen und Lernziele an einem zentralen Ort.

## Features 🎯

### Phase 1 (MVP)
- ✅ **Hausaufgaben-Management**: Erstellen, Bearbeiten, Löschen mit Status-Tracking
- ✅ **Prüfungs-Planung**: Verwaltung von Daten, Fächern und Themen
- ✅ **Lernziele**: Ziele pro Fach definieren und Fortschritt verfolgen
- ✅ **Dashboard**: Schnelle Übersicht aller anstehenden Aufgaben

### Phase 2 (Geplant)
- 📅 Kalenderansicht
- 🔔 Erinnerungen/Notifications
- 📊 Statistiken und Auswertungen
- 📁 Lernmaterialien hochladen
- 👥 Mehrbenutzer-Support

## Tech-Stack 🛠️

### Frontend
- React 18 + TypeScript
- Tailwind CSS
- Axios (API-Kommunikation)

### Backend
- Node.js + Express + TypeScript
- Prisma ORM
- PostgreSQL

## Installation 🚀

### Backend Setup
```bash
cd backend
npm install
cp .env.example .env
npm run setup
npm run dev
```

### Frontend Setup
```bash
cd frontend
npm install
npm start
```
